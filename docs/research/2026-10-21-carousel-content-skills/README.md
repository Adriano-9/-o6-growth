# Avaliacao de repositorios para conteudo e carrosseis O6

## Resumo executivo

Os quatro repositorios existem, mas nao devem ser instalados integralmente no
O6. O projeto ja possui planejamento, hooks, roteiro de Reels, voz, pesquisa de
nicho, copy e renderizacao HTML/Puppeteer. Instalar pacotes com gatilhos
semelhantes criaria rotas concorrentes e aumentaria o risco de quebrar o Brand
Book.

Decisao recomendada:

1. manter `o6-carousel` como autoridade visual;
2. avaliar importacao seletiva de capacidades do `marketingskills`;
3. aproveitar conceitos de `instagram-skills`, sem instalar o pacote inteiro;
4. testar `open-carrusel` apenas como aplicativo isolado quando o Claude voltar;
5. nao instalar `carousel-suite-skill`.
